# go-interview

Набор задач, которые встречаются на Go-собесах чаще всего. Цель — не «решить один раз», а **отточить до автоматизма**: каждая задача гоняется по кругу, пока не пишется уверенно с чистого листа.

## Правила

1. **Пишешь сам.** Без AI, без гугла решений. Доки по стандартной библиотеке — можно. Если трудно, ресерчить как работают структуры данных и алгоритмы – можно.
2. **Круг закрыт, когда `go test ./...` в папке задачи зелёный** (и для блоков A/B — зелёный с флагом `-race`).
3. **Повторный круг — с чистого листа**: удали свой код из task.go (или `git stash`) и решай заново, не подглядывая.
4. Таймбоксы: блок A/B — 30–45 минут на задачу, блок C — 20–30. Не уложился — зафиксируй, где застрял.
5. **Подсказки.** В папках части задач лежит HINTS.md — лестница из двух уровней. Порядок: 20–30 минут честной попытки → застрял — открой уровень 1 → ещё 15 минут — уровень 2.
6. Кругом может быть как повторение сразу после решения, так и заход через неделю.

## Как запускать

```bash
cd a-concurrency/01-safe-cache
go test -race ./...
```
