# Подсказки

Открывай только после 20-30 минут честной попытки. Застрял — уровень 1,
ещё 15 минут — уровень 2.

## Уровень 1 — направление

Это LRU, поднятый на уровень выше: теперь элементы сгруппированы
по частоте, и внутри КАЖДОЙ частоты нужен порядок свежести (LRU).
Подумай: map ключей — как в LRU, но куда указывают узлы?
И как за O(1) знать, какая частота сейчас минимальная?

## Уровень 2 — конструкция

Три вещи: map[ключ] -> узел; map[частота] -> двусвязный список узлов
этой частоты; minFreq — текущий минимум.
Get: вынуть узел из списка своей частоты, freq+1, положить в голову
списка новой частоты; если старый список опустел и был минимальным —
minFreq++. Set нового: вытеснить хвост списка minFreq (если полон),
вставить с freq=1, minFreq=1. Set существующего: обновить значение,
освежить позицию в СВОЁМ списке, частоту не трогать.
