# Подсказки

Открывай только после 20-30 минут честной попытки. Застрял — уровень 1,
ещё 15 минут — уровень 2.

## Уровень 1 — направление

Разложи требования на операции: найти по ключу за O(1); понять, кто самый
старый, за O(1); переместить элемент в «самые свежие» за O(1).
Одна структура всего этого не умеет. Какие две структуры дают
по половине требований — и как их склеить?

## Уровень 2 — конструкция

map[ключ] -> узел двусвязного списка. Список хранит порядок свежести:
голова — самое свежее, хвост — кандидат на вытеснение.
Get: найти в map, узел переместить в голову. Set: обновить/вставить
в голову; при переполнении удалить хвост — и из списка, и из map
(ключ для удаления из map хранится в самом узле).
Можно взять container/list; на следующем круге — свой список из задачи 01.
