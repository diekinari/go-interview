# Подсказки

Открывай только после 20-30 минут честной попытки. Застрял — уровень 1,
ещё 15 минут — уровень 2.

## Уровень 1 — направление

В произвольном порядке пересечения искать дорого — каждый с каждым.
Что нужно сделать со исходных списком, чтобы пересекающиеся интервалы оказались
соседями и хватило одного прохода?

## Уровень 2 — конструкция

Отсортируй по началу интервала. Дальше один проход с «текущим» интервалом:
следующий начинается не позже конца текущего (next[0] <= cur[1]) — слей
(расширь правую границу максимумом); иначе — зафиксируй текущий в ответ
и начни новый. Не забудь добавить последний текущий после цикла.
