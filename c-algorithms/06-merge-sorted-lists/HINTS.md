# Подсказки

Открывай только после 20-30 минут честной попытки. Застрял — уровень 1,
ещё 15 минут — уровень 2.

## Уровень 1 — направление

Два указателя идут по спискам, на каждом шаге к результату пришивается
меньший из двух текущих узлов, и его указатель сдвигается дальше.
Подумай, что делать, когда один из списков закончился.

## Уровень 2 — конструкция

Главная возня — «кто станет головой результата» и пустые списки.
Убери её фиктивным узлом: dummy := &ListNode{}, хвост результата
tail := dummy. Пока оба списка непусты — tail.Next = меньший узел,
сдвинуть его указатель и tail. После цикла пришей непустой остаток
целиком (он уже отсортирован). Ответ — dummy.Next.

Фиктивный узел — не нарушение требования: в результат он не попадает.
