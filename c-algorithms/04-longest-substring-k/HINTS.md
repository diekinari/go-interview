# Подсказки

Открывай только после 20-30 минут честной попытки. Застрял — уровень 1,
ещё 15 минут — уровень 2.

## Уровень 1 — направление

Подстрока — непрерывный кусок, значит её задают две границы. Вместо
перебора всех пар границ подумай об «окне», которое ползёт по строке:
правая граница всегда движется вперёд, левая подтягивается, только
когда внутри окна стало слишком много различных символов.

## Уровень 2 — конструкция

Скользящее окно + map счётчиков символов внутри окна. Двигай right,
увеличивая счётчик s[right]. Пока различных символов (len(map)) больше k —
уменьшай счётчик s[left] (удаляя ключ при нуле) и двигай left.
После каждого шага окно валидно — обновляй максимум длины right-left+1.
Каждый символ входит и выходит из окна по одному разу — отсюда O(n).
