# Подсказки

Открывай только после 20-30 минут честной попытки. Застрял — уровень 1,
ещё 15 минут — уровень 2.

## Уровень 1 — план

1. Замени http.ListenAndServe на явный http.Server — у него есть метод
   для вежливой остановки; srv.ListenAndServe — в отдельной горутине.
2. Канал + signal.Notify — main блокируется на чтении из него.
3. По сигналу — context.WithTimeout и srv.Shutdown(ctx).

## Уровень 2 — детали, о которые спотыкаются

- signal.Notify(quit, syscall.SIGINT, syscall.SIGTERM); канал буферизированный, ёмкости 1.
- После Shutdown метод ListenAndServe возвращает http.ErrServerClosed —
  это НЕ ошибка, а штатное завершение: проверяй через errors.Is и не падай на ней.
- srv.Shutdown(ctx) блокирует, пока активные запросы не завершатся
  или не истечёт ctx — это и есть «дожидание».
